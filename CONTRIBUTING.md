# Contributing

1. Corrections: open an issue with the template, or a pull request adding a row to `corrections/corrections.csv`
   with a source. Numbers without a source are not accepted.
2. Colleges: file from an official address and say so; we mark the correction college-confirmed.
3. Ranking publishers and other content owners: use the "Content owner request" template or email.
4. Code: the pipeline that builds this data is in a separate repo; ask in an issue if you want to help there.
5. By contributing a correction you agree it is published under CC BY 4.0 and that you have the right to share the
   source you cite. Do not include personal information about any individual.
